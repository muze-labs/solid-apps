# Initial scoped capability transport and picker

The server owns provisioned identities, route policy, connection leases and
single-settlement request state. Its HTTP adapter translates Node requests into
the same Request/Response interface used by protocol tests. No domain-specific
browse logic or Pod client is present in the broker.

The client owns connection cancellation, long polling and pending promises.
SimplyFlow owns app UI projections. Launcher sets its resource draft only after
validating a selected URL; Files supplies user-mediated selection, cancellation
and a busy response. Existing browsing and storage policy stay in Files.

The only new durable user setting is the broker origin in linked preferences.
Keys, issued connection tokens, live registrations and requests are ephemeral.
The build records and enforces the per-app gzip JavaScript budget, including
the authentication callback. No additional npm dependencies were introduced.
