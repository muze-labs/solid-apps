# Put each feature export in a component file

Date: 2026-11-07. Refinement of the still-Active CYC-20261107-QG24H-37.

The maintainer likes the features.mjs consistency, but requests a components
folder with each feature export in its own file. This authorizes a contained
organization change to the already selected suite-wide component refactor.

Each existing named feature is moved into its own kebab-case module under
src/components/ in its owning app/package. features.mjs remains an explicit
re-export index, preserving the existing import surface and consistency. Only
imports used by a component move with it; relative HTML/CSS imports are rebased.
Native data/helper modules are not reclassified as feature components.

The build's retained-source capture must follow these named re-exports and point
to the actual component file/line. SimplyFlow component names, contexts, public
handles, model/storage/rendering behavior and RDF contracts stay unchanged.
No new cycle, acceptance, commit or merge is inferred. EVD45 records verification.
