# Shared menu focus, navigation and alignment

Maintainer reports immediate WebID / connection highlighting without hover;
that highlight persists while hovering Preferences. Requests Arrow Down/Up
navigation, removal of 1–2 px gaps around rows, and vertical correction of the
user icon and dialog close icon. Corrections are local to the confirmed active
CYC49 shared UI goal; this report is not human acceptance.

Effective cause: authored autofocus plus :focus background keeps the first row
selected for pointer opening. No arrow shortcut was registered. Native popover
padding was not reset, item rules added borders, and icons/text used baseline
alignment. Installed the-ds supplies styles but no keyboard menu behavior;
SimplyFlow's public scoped shortcuts API meets the required navigation contract.

Correction: native popover opening without forced row focus; hover takes visual
precedence over keyboard focus. Shared scoped SimplyFlow Arrow Down/Up shortcuts
focus enabled visible rows and wrap at ends. Reset menu/list/item spacing; center
controls with flex and use an authored SVG x consistently in all shared dialogs.
No additional rendering, event transport or library dependencies are introduced.
