# Native workspace and app-state verification

Date: 2026-11-01. Implementation `929ba5c`; intent SRC24; design DES25.

The maintainer explicitly requested fixing retained DEF18, then clarified that
migration is unnecessary because nothing has been released. The implementation
uses the native format directly, with a fresh native cache database and a visible
refusal for retired Pod targets. No legacy JSON-in-Turtle fixture or migration
was created. Old development cache records and actual user Pod data were untouched.

Verification:

- `npm run check` passes all nine test files and the build. Thirteen native-format
  contracts cover typed RDF/IRIs, ordering, scoped app graphs, unknown predicates,
  lexical values, shared blank-node identity, cycles/lists, existing custom
  instance IRIs, independent native current/baseline graphs and local-only keys.
  They also cover draft separation, opaque-string fidelity, malformed-state and
  ownership refusal, exact graph equality and retired-format refusal.
- Fourteen persistence contracts cover conditional checkpoints, native metadata
  preservation, wrong-account/412 handling, review/retry, remote-preparation
  failure, acknowledged 205 without ETag, validator refresh, target-scoped
  accepted baselines across reload, concurrent edits, 401 and close-time dispatch.
  The controlled preparation interleaving first failed during implementation:
  an older body could be paired with a later snapshot and falsely marked clean.
  Capturing one immutable checkpoint and serializing body/metadata synchronously
  makes that case retain pending edits or refuse stale preparation; retry then
  acknowledges exactly the latest native state. Edits during PUT remain covered.
- The app-owned opaque string containing JSON, including whitespace/newline, is
  preserved verbatim through native local and Pod round-trips. No broker parsing
  or main-state data is hidden there. This is the explicitly authorized narrow
  experiment, not an endorsed general encoding.
- `npm run test:browser` passes all three Chrome suites on the final build. These
  cover all four apps, profiles/preferences/storage workflows, cross-origin
  selection, scoped grants, checkpoint/reconnect/draft retention, distinct app
  instances, local-only updates, conditional Pod saving/conflict recovery and
  fresh-browser restoration. Selecting/cancelling activates the existing
  Launcher tab without an extra tab in the isolated proof.
- Chrome 131 received the authorized native close-time PUT in the local fixture.
  This remains a bounded lifecycle observation, not guaranteed delivery or real
  Solid OIDC/DPoP shutdown verification. The fixture uses a test bearer credential;
  no real user Pod or credentials were accessed.
- Final complete JavaScript graphs including the auth callback: Launcher 198680,
  Contacts 188739, Files 171773 and Profile 188642 gzip bytes, all below 200000.
  Build enforcement confirms N3 is absent; no dependency or shared parser default
  changed, and SimplyFlow still owns rendering.
- The generated `design/examples/workspace.ttl` independently parses with RDFLib.
  Its ordered instance, typed grant, resource links and app state are native RDF,
  with no snapshot predicate or RDF JSON literal. Node tests also check native
  lexical escaping and refuse emitting an RDF JSON datatype.
- A disposable native-RDF probe confirms why the raw-triple boundary is needed:
  the installed OLDM object writer expands a shared blank node into distinct
  nodes, and a cyclic blank node raises RangeError. The workspace codec reuses
  the installed oldm-turtle parser and emits Turtle triples directly, preserving
  those identities without changing shared libraries or installing another parser.
- Spiral snapshot validation, changed-reference ancestor/artifact checks,
  branch/cycle identity and whitespace checks pass.

DEF18 is retained and recorded as fixed on the cycle branch. CYC2 remains Active
for renewed maintainer evaluation; historical ACC19 does not pre-accept this
correction. No migration, merge or publication was performed. For manual testing,
reload all apps and choose a fresh workspace URL in Preferences (for example
workspace-native.ttl) if the existing target contains the retired format. The
native cache starts fresh; previously saved shortcuts use their existing store.
