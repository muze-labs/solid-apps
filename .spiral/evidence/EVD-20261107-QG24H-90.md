## Manual review

In Contacts with some people visible, inspect the feature's named style and make
a temporary live edit through its existing ID:

```js
const swb_contact_style = document.getElementById('swb-contact-list.css');
const swb_contact_original = swb_contact_style.textContent;
swb_contact_style.textContent += '\n.person-avatar { background: rebeccapurple; }';
```

The avatars change immediately. Restore their original appearance in place:

```js
swb_contact_style.textContent = swb_contact_original;
```

This transient console check demonstrates the runtime half of the IDE connection;
it does not persist an override or replace the component original. The browser
tests additionally coordinate source overrides and installed CSS, then restore
both, including during a real unsaved profile draft. No new library API is needed.
