# Return activation and authorization popup ownership verification

Date: 2026-11-01. Implementation `2031783`; source FBK22.

The maintainer confirms Files startup/activation works and reports failed return
plus a probable leftover “Completing sign-in…” tab on protected browsing. Their
callback-message/loading recollection is uncertain; no real Pod or credentials
were used in this verification.

Before correction, disposable cross-origin Chrome probes showed opener.focus
and root self.focus both leaving Launcher hidden. A named-existing-context probe
activated Launcher without another page. This evidence changed the activation
mechanism while preserving the current workspace/opener architecture.

The new session regression test failed against the predecessor: success, denied
consent and state mismatch all left the helper-created window open. With the
correction, eight authorization/public-read scenarios pass, covering cached and
fresh identity, public reads without a popup, success, denied consent, state
mismatch, blocked popup, user closure and background refusal (success covers both
cached and fresh identity). Each verifies no orphan owned UI/listener remains.
Client construction is replaced by a fixture Metro client to trigger the session
callback without exchanging credentials; discovery and the published popup
helper are real. The existing account-scoped logout regression also passes.

`npm run test:picker` passes all sixteen direct transport/policy contracts and
the isolated Chrome proof. It now asserts Launcher becomes visible after both
selection and cancellation, and that returning does not create a blank/duplicate
tab. Cross-origin cold startup, warm reuse after transient activation expires,
provider activation, exact full resource URL and cancellation remain verified.
Both return observations are true; the predecessor EVD21 recorded both false.
Browser policy can still refuse focus in other environments; manual guidance
remains. This is Chrome headless evidence, not a Firefox or graphical certification.

`npm run build` passes: Launcher 193543, Contacts 185669, Files 169046 and Profile
185520 gzip bytes including the auth callback, all below 200000. Whitespace,
Spiral snapshot validation and changed-reference ancestor/artifact checks pass.

Full `npm run check` and `npm run test:browser` remain deliberately unrun because
their existing persistence tests write the forbidden main-state JSON-in-Turtle
encoding retained as Open DEF18. These focused tests/build write no such state.
There is no persistence migration, dependency update, live Pod validation, merge
or publication. CYC2 remains Active for renewed manual evaluation; reload both
Launcher and Files to load the new handshake and session code. ACC19 remains
historical acceptance of the earlier snapshot.
