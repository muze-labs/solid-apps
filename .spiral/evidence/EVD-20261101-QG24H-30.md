# Readable Turtle base/prefix verification

Date: 2026-11-01. Implementation `8bbc583`; source SRC29.

StateGraph emits the supplied document base, used vocabulary prefixes and grouped
subject properties. It keeps resolved source bindings during cloning, allocates
noncolliding aliases for common vocabularies, and uses installed OLDM URI helpers
for relative spelling/prefix escaping. Absolute comparison keys, raw blank-node
identity, explicit literal datatypes and native workspace schema remain unchanged.

Evidence:

- `npm run check` passes all 85 tests and the build. Three new serialization
  contracts check requested output spelling, grouping, re-parsing against a
  different retrieval URL, preserved source prefix bindings and collisions,
  exact queries/fragments/percent escapes/Unicode, and unchanged literal text.
  Existing graph/preservation, baseline/conflict, retired-snapshot cleanup,
  opaque-string and save-timing tests remain passing.
- The generated example independently parses with RDFLib and is isomorphic to
  its previous absolute-IRI version: exactly the same 17 triples and literal
  datatypes. Its size falls from 2720 to 1125 bytes. Explicit xsd:string spelling
  is retained under the prefix so even RDFLib's strict literal representation
  matches the earlier output.
- All three browser scripts pass individually on the final build: general apps,
  managed-workspace save/conflict/close/restore, and isolated cross-origin picker
  activation/return. The first combined `npm run test:browser` run passed the
  general suite but hit a transient not-ready/restoring state while expecting a
  conflict in the managed fixture. The unchanged managed script then passed.
  Another combined run hit Profile startup readiness in the general suite; the
  unchanged general script then passed independently. The picker script passed
  independently as well. These intermittent readiness failures remain recorded;
  the combined command is not claimed green and no product or fixture changes
  were made to hide them. Their cause is not established by this verification.
- The passing managed run received an authorized close-time fixture write.
  This remains bounded Chrome fixture evidence, not a general shutdown-delivery
  guarantee or real Solid OIDC/DPoP test. No actual user Pod was accessed.
- Final gzip JavaScript graphs including auth callback: Launcher 199381,
  Contacts 189412, Files 172447 and Profile 189313 bytes. All remain below 200000;
  build confirms N3 is absent. No dependencies or shared library defaults changed.
- Spiral snapshot validation, changed-reference ancestor/artifact checks,
  branch/cycle identity and whitespace checks pass.

The implementation changes Turtle text presentation while preserving the RDF
model and workspace contracts. CYC2 remains Active for human evaluation; no merge
or publication was performed. Reload Launcher and use Save to Pod to emit the
readable format at the current workspace URL. Existing valid files need no
migration; base/prefix directives are supported by the existing parser.
