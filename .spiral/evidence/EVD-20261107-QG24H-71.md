## Failed probes and correction evidence

Initial popup fixtures assumed eager client setup and the old sign-in wording;
they were adapted to lazy request-scoped configuration and the new contract.
Browser-fixture issues included serializing an app object instead of a boolean,
using a task URL without supplying a capability request, selecting the host's
capability frame instead of the fixture frame, and serving SVG with the wrong
MIME type. These were corrected; they were not treated as product evidence.
An intermediate disposable run also reported Failed to fetch; a cause was not
established, and later isolated runs pass. CYC49's earlier intermittent fetch
issue remains retained rather than declared fixed by this cycle.

Native Escape exposed a real non-cancellable CloseWatcher/delayed-close race.
The recovery behavior now leaves non-cancellable completion to the browser and
uses shared motion for cancellable requests. A delayed-token probe then proved
one queued PUT after explicit cancellation; request-scoped transport gating
corrects it and the controlled regression now expects zero writes. Successful
close is distinct from cancellation. Already dispatched writes cannot be undone.
The embedded empty-header CSS would hide the new notice; its visibility condition
was corrected and is now tested in an actual iframe.

Firefox uses an isolated disposable WebDriver adapter. Earlier driver shutdown
emitted EACCES after the WebDriver session had been deleted; that cleanup message
is distinct from product assertions. Test logs retain it rather than hide it.

messages. This does not address the separate general account/logout ownership,
automatic-sync, provider-registry or individual app/Preferences redesign work.
