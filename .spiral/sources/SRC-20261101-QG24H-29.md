# Readable workspace Turtle with a base and prefixes

The maintainer requests: “Lets add a base url to the workspace and prefixes so
we don't get this long list of full uri's”. The current StateGraph emitter and
generated example confirm that every named term is an absolute IRI and each
triple repeats its subject. This is a presentation gap, not a new schema.

Emit the actual document base, compact vocabulary prefixes and grouped subject
properties. Reuse the installed OLDM URI helpers, preserve valid source prefix
bindings and avoid collisions. Relative references must resolve to precisely the
original IRI, including query, fragment, Unicode and percent escapes. Keep raw
blank-node identity, lexical values, unknown RDF and the existing explicit
retired-snapshot cleanup/write restrictions. No migration or semantic change
is intended. Stay in the current cycle; no merge or publication is authorized.
